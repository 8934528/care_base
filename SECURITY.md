# Security Policy

## Supported Versions

The following versions of CareBase are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

I take the security of our system seriously. If you find a security vulnerability, please do not report it publicly.

To report a vulnerability, please:

1. Email the development team at [EMAIL_ADDRESS] (Placeholder)
2. Provide a detailed description of the vulnerability.
3. Include steps to reproduce the issue.

I will respond to your report within 48 hours and work towards a resolution.
