# Contributing to care_base

I welcome contributions! Please follow these guidelines to ensure a smooth development process.

## Getting Started

1. **Fork the repository** and create your branch from `main`.
2. **Follow the Setup Guide** in the main [README.md](../README.md).
3. **Use the Makefile** to manage your development environment.

## Code Standards

- **Backend (.NET)**: Follow standard C# naming conventions and Clean Architecture principles.
- **Frontend (React)**: Use functional components with hooks and TypeScript for type safety.
- **Commit Messages**: Use clear, descriptive commit messages (e.g., `feat: add patient registration`, `fix: queue sorting bug`).

## Pull Request Process

1. Ensure all tests pass (if applicable).
2. Update documentation if your changes affect the system architecture or structure.
3. Submit a PR with a detailed description of the changes.

## Bug Reports

Open an issue with the "bug" label, providing as much detail as possible (logs, screenshots, steps to reproduce).
